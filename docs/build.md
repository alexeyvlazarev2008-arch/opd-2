# Описание сборки и структуры проекта (DevOps)

## Настройки сборки (Build Settings)
- Целевая платформа: Windows
- Доступные платформы: x86_64

## Установленные пакеты (Package Manager)
- Simple 2D Template
- Multiplayer Center

## Структура папок проекта
- `Assets/Settings` — настройки проекта.
- `Assets/IndieMarc` — основная папка с ассетами шаблона Simple 2D Template от Indie Marc.
  - `Assets/IndieMarc/TopDownDemo` — демо-версия игры в жанре Top-Down (наш основной проект). Содержит сцены, префабы, скрипты и ассеты для top-down геймплея.
  - `Assets/IndieMarc/PlatformerDemo` — демо-версия игры в жанре 2D-платформер (не используется в текущем проекте).
  - `Simple2DTemplate` — документация к шаблону.
  - `icon`.

## Ассеты и размер
- В проекте используются 2D-спрайты, материалы, префабы и скрипты из пакета "Simple 2D Template" от Indie Marc.
- Приблизительный размер проекта: 72 Мб.
